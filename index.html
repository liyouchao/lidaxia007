  • 参与需求评审、技术设计评审、通过经验对需求进行测试任务拆分、测试工时评估、合理分配测试资源进行测试，分配好测试任务后，组织测试用例评审，提供冒烟用例，测试阶段组织测试进度会议，总结测试进度情况、开发缺陷情况，风险影响等
  • 在项目管理 jira 中提交和跟踪 bug，确保 Bug 已修复并进行回归测试，总结统计不同缺陷，按需进行项目复盘
  • 对高使用的场景用 Jmeter 执行接口性能测试，通过断言检查服务器返回结果和预期结果是否一致，对接口进行压力测试，进入服务器查看 cpu、内存等运行情况，总结性能测试结论
  • 在业务大版本上线后，推动接口自动化（pytest+alluure+yaml）使用，提高测试回归的效率，分配组员维护各自模块的接口脚本，我主要负责接口自动化框架搭建，基础日志模块、登录模块、底层模块维护，并在 docker 上维护好 Python 环境，然后在 Jenkins 上搭建好任务
  • 定期总结测试项目的经验文档、在组内组织不定期组织培训、每周站会，鼓励大家多总结多记录多沉淀，完成大家共同进步成长
  • 编写制定专项测试策略（弱网测试、兼容测试、接口测试等），对系统进行专项测试（主要功能场景），并且输出对应专项测试测试报告
